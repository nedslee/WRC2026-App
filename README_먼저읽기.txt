WRC 2026 현장 가이드 · Release 1.0.4

# 이번 데이터 안전성 핫픽스
- 현장 메모 입력창 아래에 `저장 중…` / `저장됨` / `저장 실패` 상태 표시 추가
- 기존 0.35초 자동 저장은 그대로 유지
- 업체 상세창을 닫을 때 Android 시스템 뒤로가기/화면의 닫기 버튼 어느 쪽이든 마지막 메모 내용을 IndexedDB에 즉시 한 번 더 저장
- 빠르게 입력 후 바로 닫더라도 오래된 지연 자동저장이 최신 메모를 덮어쓰지 않도록 메모 저장 작업을 순차 처리
- 마지막 저장에 실패하면 업체창을 닫지 않고 오류 상태를 표시하도록 보호
- 기존 업체 DB/방문기록/메모/사진/고해상도 지도/동선 이미지용 IndexedDB 이름은 그대로 유지하므로 기존 설치 데이터와 호환
- 앱/서비스 워커 오프라인 캐시 버전을 Release 1.0.4로 갱신

# GitHub Pages 업데이트
1. `WRC2026_Release_v1.0.4_PWA.zip`을 PC에 다운로드하고 압축 해제
2. GitHub → `nedslee/WRC2026-App` → `Add file` → `Upload files`
3. 압축을 푼 폴더 안의 파일/폴더 전체를 저장소 최상위로 업로드
4. `Commit changes` 클릭
5. Pages 설정은 변경하지 않음
6. 휴대폰을 온라인 상태로 두고 앱을 완전히 종료했다가 다시 실행
7. 업체 하나를 열어 메모를 입력하고 `저장 중…`이 `저장됨`으로 바뀌는지 확인
8. 메모를 입력하자마자 Android 뒤로가기로 닫은 뒤 업체를 다시 열어 마지막 내용이 남아 있는지 확인
9. 결과 → 오프라인 준비 상태에서 Release 1.0.4 캐시가 준비됐는지 확인
10. 비행기 모드에서 앱을 완전히 종료/재실행해 검색·업체 상세·지도·동선을 확인

# 출장 중 데이터 보호 권장
- 하루 일정이 끝나면 `결과 Excel 내보내기`와 `전체 백업 JSON`을 각각 한 번 생성하는 것을 권장합니다.
- 앱 제거, Chrome/브라우저 저장 데이터 삭제, Android의 앱 데이터 삭제는 현장 기록을 지울 수 있으므로 출장 중에는 하지 마세요.
- 메모의 `저장됨` 표시는 해당 메모 내용의 IndexedDB 기록 완료를 의미합니다.
