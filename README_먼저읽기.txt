WRC 2026 현장 가이드 · Release 1.0
자료 버전: v0.6 (2026-08-18) / 264개 업체 / 방문계획 51개

[중요] 이 ZIP은 APK 설치파일이 아닙니다. 폴더 전체를 HTTPS 웹서버에 올린 뒤 휴대폰에서 접속해 PWA로 설치합니다.

출국 전 설치 순서
1. 이 폴더의 내용 전체(index.html, sw.js, manifest.webmanifest, icons 폴더 포함)를 같은 HTTPS 주소에 업로드합니다.
2. 각 휴대폰에서 해당 HTTPS 주소/index.html에 접속합니다.
3. Android Chrome: 메뉴 > 앱 설치 또는 홈 화면에 추가. iPhone Safari: 공유 > 홈 화면에 추가.
4. 홈 화면의 WRC 2026 아이콘으로 다시 실행합니다.
5. 사용자 이름을 각자 입력합니다.
6. 지도 메뉴에서 보유한 고해상도 HALL FULL/A/B/C/D1/D2 원본을 각 휴대폰에 직접 등록합니다. 앱은 등록 원본을 재압축하지 않습니다.
7. 결과 > 오프라인 준비 상태 > 다시 점검에서 자료 v0.6 / 264개 업체, 앱 캐시, 지도, 내부 저장소, 백업 기능을 확인합니다.
8. 마지막으로 비행기 모드로 바꾸고 앱을 완전히 종료한 뒤 홈 화면 아이콘으로 재실행하여 검색/업체상세/지도가 열리는지 확인합니다.

현장 사용
- 서버 로그인/외부 API/실시간 동기화 기능은 없습니다.
- 각 휴대폰의 방문 체크, 메모, 사진, 사용자 지도는 해당 휴대폰 내부 IndexedDB에 독립 저장됩니다.
- 3명의 기록은 자동 합쳐지지 않습니다.

출장 후
- 결과 > 결과 Excel 내보내기: 업체정보 + 방문여부 + 방문일시 + 사용자 + 메모 + 사진 수를 XLSX로 저장합니다.
- 결과 > 전체 백업 JSON: 업체/방문기록/메모/사진을 복원 가능한 단일 백업으로 저장합니다.
- 세 명이 각각 결과 파일과 백업 파일을 내보낸 뒤 공유하면 됩니다.

데이터 업데이트
- 기본 내장 자료는 v0.6입니다.
- 이후 새 Excel이 생기면 결과 > 새 Excel 불러오기로 업데이트할 수 있습니다. UID가 같은 업체의 방문기록/메모/사진은 유지됩니다.
- Release 1.0은 프로토타입과 별도의 내부 저장소를 사용하므로 기존 테스트 기록이 섞이지 않습니다. 각 휴대폰에서 Release 1.0을 처음 실행하면 v0.6 내장 자료로 새로 시작합니다.

비상용
- WRC2026_Release_v1.0_Standalone.html은 설치 없이 여는 비상용 단일 HTML입니다. 기능과 로컬 저장은 동작하지만 Service Worker/PWA 설치 점검은 할 수 없으므로 주 사용은 설치형 PWA를 권장합니다.
- sample-data 폴더에 v0.6 Excel 원본을 함께 넣었습니다.

주의
- 브라우저 앱 데이터/사이트 데이터를 직접 삭제하면 휴대폰 내부 기록이 지워질 수 있습니다. 중요한 기록은 출장 중에도 '전체 백업 JSON'으로 수시로 내보내는 것을 권장합니다.
- 고해상도 지도는 파일 크기에 따라 휴대폰 저장공간을 많이 사용할 수 있습니다.
