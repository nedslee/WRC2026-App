WRC 2026 현장 가이드 · Release 1.0.2

# 이번 핫픽스
- 오프라인 준비 상태가 잘못된 v1.0.0 캐시명을 찾던 버그 수정
- Service Worker / 점검기 모두 `wrc2026-release-v1-0-2`로 통일
- 찡그린 임시 아이콘을 웃는 로봇 `WRC 26` 아이콘으로 교체
- 현장 지도 화면에 `1일차 동선 · 8/20(목)`, `2일차 동선 · 8/21(금)` 이미지 슬롯 추가
- 동선 이미지는 PNG/JPG/WebP 원본을 앱 내부에 그대로 저장하고, 홀 지도와 같은 핀치 줌/드래그 뷰어로 열람
- 동선 이미지는 선택 기능이므로 미등록 상태여도 오프라인 준비 상태를 실패/경고로 만들지 않음
- 업체 DB/방문기록/메모/사진용 IndexedDB 이름은 그대로 유지하므로 기존 설치 데이터와 호환

# 동선 파일 준비 권장 방식
1. PowerPoint에서 첫날 동선 슬라이드와 둘째날 동선 슬라이드를 각각 준비
2. 가능하면 `PNG`로 내보내기 (PDF보다 앱 내 오프라인 열람과 확대가 단순하고 안정적)
3. 휴대폰 앱 → 지도 → 현장 동선 → 1일차/2일차 `동선 이미지 등록`
4. 등록 후 이미지를 눌러 확대하고 핀치 줌/드래그가 되는지 확인

PDF를 그대로 넣는 기능은 이번 릴리즈에는 넣지 않았습니다. Android PWA에서 브라우저 PDF 뷰어 의존성이 생길 수 있어 출장 현장 안정성을 우선했습니다. PPT에서 PNG/JPG로 내보내는 방식을 권장합니다.

# GitHub Pages 업데이트
1. `WRC2026_Release_v1.0.2_PWA.zip`을 PC에 다운로드하고 압축 해제
2. GitHub → `nedslee/WRC2026-App` → `Add file` → `Upload files`
3. 압축 푼 폴더 안의 파일/폴더 전체를 저장소 최상위로 업로드
4. 같은 이름의 `index.html`, `manifest.webmanifest`, `sw.js` 등은 새 버전으로 교체
5. `icons/icon-192-v102.png`, `icons/icon-512-v102.png`도 반드시 같이 업로드
6. 아래 `Commit changes` 클릭
7. Pages 설정은 변경하지 않음
8. 수 분 뒤 앱을 온라인 상태에서 한 번 실행한 뒤 완전히 종료/재실행
9. 결과 → 오프라인 준비 상태에서 앱 캐시가 Release 1.0.2로 정상 표시되는지 확인
10. 비행기 모드에서 다시 실행

# 아이콘이 예전 얼굴로 남는 경우
Android 런처/Chrome이 설치 아이콘을 오래 캐시할 수 있습니다. 새 버전에서 아이콘 파일명을 바꿨기 때문에 대개 갱신되지만, 계속 예전 아이콘이면 앱을 제거한 뒤 GitHub Pages에서 다시 설치하면 확실히 바뀝니다. 앱을 제거하기 전에 현장 기록이 있다면 반드시 `전체 백업 JSON`을 먼저 저장하세요.

# 최종 출장 점검
- 사용자 이름 설정
- 최신 업체 데이터 확인
- 고해상도 홀 지도 원본 등록
- 필요하면 1일차/2일차 동선 PNG/JPG 등록
- 결과 → 오프라인 준비 상태 재점검
- 비행기 모드 → 앱 완전 종료 → 재실행
- 업체 검색 / 상세 / 지도 / 동선 열람 확인
- 전체 백업 JSON 1회 생성
